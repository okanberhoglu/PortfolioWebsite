3D Topology Optimization

A SIMP-based structural optimization solver that distributes material efficiently within a 3D design domain under given loads and boundary conditions.

Overview

Project Overview

This project implements a 3D topology optimization algorithm based on the Solid Isotropic Material with Penalization (SIMP) method. The goal is to find the optimal material distribution within a given design domain that minimizes structural compliance (maximizes stiffness) subject to a volume fraction constraint. The solver iteratively redistributes density values across finite elements using sensitivity analysis derived from the adjoint method, converging to a binary-like density field that represents the optimal structural layout.

The implementation handles arbitrary 3D domains discretized with hexahedral finite elements, applies boundary conditions and point or distributed loads, and produces a density field that can be exported and post-processed into a manufacturable geometry. Filtering schemes such as the density filter are used to avoid checkerboard instabilities and ensure mesh-independent results.

Methodology

Optimization Method

The SIMP method penalizes intermediate density values by raising the element stiffness to a power of the density, driving the solution toward a solid-void distribution. Sensitivities of the compliance objective with respect to element densities are computed efficiently using the adjoint approach, requiring only a single additional linear solve per iteration. The Optimality Criteria (OC) update scheme adjusts densities at each iteration to satisfy the Karush–Kuhn–Tucker conditions while enforcing the volume constraint through a bisection method on the Lagrange multiplier.

Formulation
  • Objective — minimize structural compliance C = F·U subject to a material volume fraction constraint
  • SIMP penalization — element stiffness K_e = ρ_e^p · K_e^0 with penalty factor p = 3
  • Sensitivity — ∂C/∂ρ_e computed analytically via adjoint method without additional solves
  • Density filter — weighted average filter applied to sensitivities to ensure mesh independence
Implementation
  • FEA solver — 8-node hexahedral elements assembled into a global stiffness matrix solved with a sparse direct solver
  • OC update — Optimality Criteria with bisection on the Lagrange multiplier for the volume constraint
  • Convergence — iteration terminates when the maximum density change falls below a tolerance of 0.01
  • Visualization — density field exported and rendered as an isosurface for 3D result inspection
Features

Key Features

3D SIMP topology optimization — the solver operates on full three-dimensional hexahedral meshes, enabling structural optimization of volumetric design domains beyond the limitations of 2D approaches.
Finite element analysis — an 8-node hexahedral FEA kernel assembles the global stiffness matrix and solves the linear system to compute nodal displacements at each optimization iteration.
Adjoint sensitivity analysis — compliance sensitivities with respect to all element densities are computed analytically in a single pass, keeping the per-iteration cost independent of the number of design variables.
Density filtering — a spatial averaging filter prevents checkerboard instabilities and makes the converged topology independent of the mesh refinement level.
Optimality Criteria update — the OC scheme with bisection efficiently updates densities at each iteration while exactly satisfying the prescribed volume fraction constraint.
3D result visualization — the converged density field is rendered as an isosurface, providing an intuitive view of the optimized structural topology and its load-bearing members.
